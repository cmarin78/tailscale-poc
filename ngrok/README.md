# Helios POC — ngrok integration

**Why ngrok:** Tailscale SaaS needs to be able to call your IdP (Authentik) to validate the SSO callback flow. If Authentik is at `localhost:9000` on your laptop, Tailscale can't reach it.

ngrok creates a public HTTPS tunnel to your localhost. Your Authentik becomes reachable at `https://something.ngrok-free.app` (or a custom domain if you pay).

## Setup

### 1. Get ngrok + authtoken

```bash
# Install ngrok (Mac)
brew install ngrok

# Or download from https://ngrok.com/download

# Create a free account at https://dashboard.ngrok.com/signup
# Copy your authtoken from https://dashboard.ngrok.com/get-started/your-authtoken

ngrok config add-authtoken <YOUR_AUTHTOKEN>
```

### 2. Bring up Authentik first

```bash
heliosctl start identity
# Wait ~30s for Authentik to be ready
curl -fsS http://localhost:9000/-/health/live/  # should respond
```

### 3. Bring up ngrok (tunnel to Authentik)

```bash
docker compose -f ngrok/docker-compose.ngrok.yml up -d

# See the public URL that ngrok assigned:
docker compose -f ngrok/docker-compose.ngrok.yml logs ngrok | grep "started tunnel"
# → "started tunnel: obj.calm-bear.ngrok-free.app → http://authentik-server:9000"
```

The public URL looks like `https://obj.calm-bear.ngrok-free.app`.

### 4. Configure Authentik

Authentik needs to know that its public URL is the ngrok one (not `localhost:9000`). This is configured in `docker-compose.identity.yml`:

```yaml
authentik-server:
  environment:
    - AUTHENTIK_HOST=https://obj.calm-bear.ngrok-free.app  # ← CHANGE THIS
```

Restart Authentik after:

```bash
heliosctl stop identity
heliosctl start identity
```

### 5. Configure Tailscale SaaS as OIDC client

In the Tailscale admin console:
https://login.tailscale.com/admin/settings/sso

Connect with:
- **Issuer URL**: `https://obj.calm-bear.ngrok-free.app/application/o/helios-tailnet/`
- **Discovery URL**: `https://obj.calm-bear.ngrok-free.app/.well-known/openid-configuration`
- **Client ID**: `helios-tailnet-client` (created by `seed.py`)
- **Client Secret**: the one generated by the seed (you can see it in the Authentik admin UI)

Tailscale will validate the IdP and show it as "Connected".

### 6. Test the flow

1. Logout of Tailscale
2. Login → "Sign in with Authentik" (or similar) should appear
3. Click → you get redirected to Authentik (at the ngrok URL)
4. Log in with `maya.admin@helios.example` / seed.py password
5. You come back to Tailscale, now logged in with SSO
6. The `platform-eng@helios.example` group (or whichever) should be associated

### 7. Apply the policy with groups

Once SSO works and the groups are provisioned:

```bash
python3 ../tools/tsctl.py policy set acl/policy.hujson

# If it says "groups not found", wait 1-2 min and retry
# (groups take a moment to appear via OIDC discovery)
```

## Free ngrok limitations

| Limit | Impact |
|---|---|
| Random URL on every restart | You must update `AUTHENTIK_HOST` on every restart |
| 1 GB/month of bandwidth | OK for POC; not for prod |
| 20 connections/min | OK for POC |
| "Visit ngrok.com" message in the browser | Just annoying, not blocking |

## Alternative: custom domain (recommended for demos)

If you're going to show the POC several times, pay ngrok ($8/month) and reserve a custom domain:

```bash
# Reserve domain (e.g. helios.ngrok.app) in the dashboard
# Update docker-compose:
environment:
  - NGROK_DOMAIN=helios.ngrok.app
```

URL stays fixed: `https://helios.ngrok.app` always.

## Alternative: cloudflared (free, own domain)

```bash
# Install cloudflared
brew install cloudflared

# Log in
cloudflared tunnel login

# Create tunnel
cloudflared tunnel create helios-poc

# Configure (creates ~/.cloudflared/config.yml)
cloudflared tunnel route dns helios-poc helios.your-domain.com
```

Pro: free, custom domain, no strict rate limits.
Con: more initial setup.
