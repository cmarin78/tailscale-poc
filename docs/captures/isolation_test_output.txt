[5] eng-operator NO puede llegar a rds-sim directamente

   [BLOCKED — esperado sin tailnet]

===== Conclusión =====
Las personas (eng-operator, etc.) NO pueden alcanzar los servicios directamente.
En el POC real con Tailscale corriendo, el overlay del tailnet rutea entre estos hosts
usando tags y ACLs. El docker network isolation actual es el 'sandboxing' que
fuerza a que TODO tráfico cross-service pase por Tailscale.
